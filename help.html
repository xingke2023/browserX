软件特色

BrowserX 把智能助手和浏览器放在同一个窗口里：你用中文说要做什么，助手直接在右边的浏览器里帮你点、帮你填、帮你查，你全程都看得到。

说话就能操作网页

打开网站、搜索、点击、填写表单、读取页面内容，一句话交给助手。

登录状态一直保留

右侧浏览器会记住你登录过的网站，重启软件也不用重新登录。

常用流程做成工具

重复的操作做成一个工具，以后填几个参数、点一下就跑完，不经过对话、不花额度。

录一遍就能自动化

手工操作一遍并录制，助手会分析网站接口，帮你做成稳定、快速的工具。

草稿保护

新建或修改工具都先写在草稿里，试运行没问题再放进工具箱，不会弄坏正在用的版本。

工具可分享

工具能导出成一个文件发给同事，导入前会列出它用到的敏感能力并可查看源代码。

不只是浏览器

助手还能读写电脑上的文件、执行命令，整理数据、导出表格都可以。

安全提醒

录制时自动给密码、令牌打码；导出工具前会检查代码里有没有写死的密码。

使用说明

1. 界面

  • 左侧：和助手的对话。顶部有「新对话」「历史」「工具箱」和 ⚙ 设置。
  • 右侧：浏览器。上方是地址栏、前进后退刷新、录制按钮和开发者工具。
  • 中间的分隔线可以拖动，调整左右两边的宽度。点左上角「BrowserX」会打开门户网站。

2. 和助手对话

  • 在左下角输入框里写你要做的事，按 Enter 发送，Shift+Enter 换行。
  • 例子：「打开 baidu.com 搜索 BrowserX」「把这个页面的表格整理成 Excel 存到桌面」。
  • 助手执行过程中可以点「停止」或按 Esc 中断。
  • 助手有时会弹出选择题，点选后按「提交」；不想回答可以点「跳过」。
  • 需要登录、扫码、输入验证码的地方，请自己在右侧浏览器里完成，再告诉助手继续。

3. 新对话与历史

  • 「新对话」会清空左侧，开始一个全新的话题。
  • 「历史」列出之前的对话，点一条就能接着聊；也可以重命名或删除。

4. 设置

  • 工作目录：助手读写文件、执行命令的文件夹。更换后会开始新对话。
  • 模型：可随时切换，当前对话会继续。
  • 权限模式：「每次询问」最稳妥，每个操作都会先问你；「全部允许」最省事，但助手的操作不再确认，请谨慎使用。
  • 主页：启动时右侧浏览器打开的网址。

工具箱

运行工具

  1. 点顶部「工具箱」，可以用搜索框按名称或描述查找。
  2. 点一个工具展开，填好参数，点「运行」。结果会显示在对话区。
  3. 运行失败时点「让助手诊断并修复」，助手会查明原因并修好工具。

工具运行时会使用右侧浏览器里已登录的网站，所以先确认相关网站已经登录。

制作新工具

  1. 在工具箱点「＋ 新建工具」，填写英文工具名、中文名和要做什么，点「开始制作」。
  2. 顶部会出现「正在制作工具」横幅。需要的话点「录制」，在右侧浏览器里手工操作一遍再点停止，录制结果会自动交给助手。
  3. 助手写好后点「试运行」测试；不对就在对话里告诉助手怎么改。
  4. 没问题后点「完成」，工具放进工具箱，当前对话里马上能用。不想要了就点「放弃」。

修改、导出、导入

  • 工具卡片上的「编辑」会进入同样的制作流程，改完点「完成」才替换原工具。
  • 「导出」把工具存成一个 .js 文件，可以发给别人。
  • 「导入工具」选择别人给的文件，先预览风险和源代码，确认后才导入。只导入你信任的人给的工具。

常见问题

右侧浏览器空白或显示「页面没有打开」

多半是回到了表单提交后的结果页，或网络切换了。点「返回上一页」重新操作，或点「重试」。

工具提示没有登录

在右侧浏览器里打开对应网站重新登录，再运行工具。

录制的文件在哪里

菜单「帮助 → 打开录制文件夹」。里面可能有业务数据，请勿外传。

工具文件在哪里

菜单「帮助 → 打开工具箱文件夹」。建议通过工具箱的「编辑」修改，不要直接改文件。

快捷键

  • ⌘+, 打开设置　⌘+L 选中地址栏　⌘+R 刷新界面
  • Enter 发送　Shift+Enter 换行　Esc 停止助手
