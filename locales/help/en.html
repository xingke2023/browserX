Features

BrowserX puts a smart assistant and a browser in the same window: just tell it in plain language what you want to do, and the assistant clicks, fills in, and looks things up for you directly in the browser on the right, while you watch every step.

Operate web pages by talking

Open websites, search, click, fill in forms, read page content: hand it all to the assistant in a single sentence.

Stay signed in

The browser on the right remembers the websites you've signed in to, so you don't need to sign in again even after restarting the app.

Turn common workflows into tools

Turn repetitive tasks into a tool. Next time, just fill in a few parameters and click once to run it, with no chat and no usage quota spent.

Record once, automate forever

Perform a task manually once while recording, and the assistant will analyze the website's APIs and build a stable, fast tool for you.

Draft protection

New or modified tools are written as drafts first and only go into the Toolbox after a successful test run, so the version you're using never gets broken.

Shareable tools

Tools can be exported as a single file and sent to colleagues. Before importing, the sensitive capabilities a tool uses are listed, and you can view its source code.

More than a browser

The assistant can also read and write files on your computer and run commands, so it can organize data and export spreadsheets too.

Security reminders

Passwords and tokens are automatically masked during recording, and before a tool is exported, its code is checked for hard-coded passwords.

User Guide

1. Interface

  • Left side: Your conversation with the assistant. At the top are "New Chat", "History", "Toolbox", and ⚙ Settings.
  • Right side: The browser. At the top are the address bar, back/forward/refresh buttons, the record button, and developer tools.
  • Drag the divider in the middle to adjust the width of the two sides. Click "BrowserX" in the top-left corner to open the portal website.

2. Chatting with the assistant

  • Type what you want done in the input box at the bottom left. Press Enter to send and Shift+Enter for a new line.
  • Examples: "Open baidu.com and search for BrowserX", "Turn the table on this page into an Excel file and save it to the desktop".
  • While the assistant is working, click "Stop" or press Esc to interrupt it.
  • The assistant may sometimes show a multiple-choice question. Make your selection and click "Submit"; if you'd rather not answer, click "Skip".
  • Wherever you need to sign in, scan a QR code, or enter a verification code, please do it yourself in the browser on the right, then tell the assistant to continue.

3. New chats and history

  • "New Chat" clears the left side and starts a brand-new topic.
  • "History" lists your previous conversations. Click one to pick up where you left off; you can also rename or delete them.

4. Settings

  • Working directory: The folder where the assistant reads and writes files and runs commands. Changing it starts a new chat.
  • Model: Can be switched at any time; the current chat will continue.
  • Permission mode: "Ask every time" is the safest, as you'll be asked before each action; "Allow all" is the most convenient, but the assistant's actions will no longer require confirmation, so use it with caution.
  • Home page: The URL the browser on the right opens at startup.

Toolbox

Running a tool

  1. Click "Toolbox" at the top. You can use the search box to find tools by name or description.
  2. Click a tool to expand it, fill in the parameters, and click "Run". The results appear in the chat area.
  3. If a run fails, click "Ask the assistant to diagnose and fix", and the assistant will find the cause and fix the tool.

Tools use the websites you're signed in to in the browser on the right, so make sure you're signed in to the relevant websites first.

Creating a new tool

  1. In the Toolbox, click "New Tool", fill in the Chinese tool name (required), the English tool name (optional; assigned automatically if left blank), and what it should do, then click "Start Building".
  2. A "Building tool" banner appears at the top. If needed, click "Record", perform the task manually once in the browser on the right, then click Stop. The recording is automatically handed to the assistant.
  3. Once the assistant has written the tool, click "Test Run" to test it. If something's wrong, tell the assistant in the chat how to change it.
  4. When everything works, click "Done". The tool goes into the Toolbox and can be used right away in the current chat. If you no longer want it, click "Discard".

Editing, exporting, and importing

  • "Edit" on a tool card enters the same building process; the original tool is only replaced once you click "Done".
  • "Export" saves the tool as a .js file that you can send to others.
  • "Import" lets you select a file someone gave you. You'll first preview its risks and source code, and it's only imported after you confirm. Only import tools from people you trust.

FAQ

The browser on the right is blank or shows "Page not opened"

Most likely you've gone back to a results page after a form submission, or your network changed. Click "Go back" to redo the action, or click "Retry".

A tool says I'm not signed in

Open the corresponding website in the browser on the right, sign in again, then run the tool.

Where are the recording files?

In Finder, press ⌘⇧G and enter ~/Library/Application Support/BrowserX/recon. They may contain business data, so please don't share them.

Where are the tool files?

In Finder, press ⌘⇧G and enter ~/Library/Application Support/BrowserX/tools. We recommend making changes through "Edit" in the Toolbox rather than editing the files directly.
